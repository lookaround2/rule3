# Adversarial Reviewer Checklist

Before returning a pathway package, ask:

- Did we overgeneralize from one case?
- Did we confuse rule text with commentary?
- Did we confuse current ARC with predecessor rules?
- Did we treat public filing as admissibility?
- Did we treat use permission as evidentiary weight?
- Did we ignore contrary ABCA or SCC authority?
- Did we use a duplicate or stub graph node?
- Did we fail to mark analogue-only authority?
- Did we omit privilege, non-party privacy, sealing, or restricted-access issues?
- Did we propose graph writes without exact IDs?
- Did we mark filing-ready without public verification?
- Did we fail to separate source material, use purpose, proceeding relationship, and remedy?
- Did any case merely cite the rule without applying or interpreting it?
- Did any reform proposal get treated as current law?
- Did the final response disclose manual validation remaining?

If any answer is yes, revise before finalizing.
