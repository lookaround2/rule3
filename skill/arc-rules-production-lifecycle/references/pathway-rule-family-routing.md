# Rule Family Routing

Use this guide to decide which workflow branches to load for a selected Alberta Rules of Court rule.

| Rule family | Route | Required classifiers |
|---|---|---|
| Part 3 pleadings / strike / summary dismissal | pleading-risk pathway | claim type, remedy, strike risk, pleadings record |
| Part 4 delay / dismissal | delay-remedy pathway | timeline, step history, prejudice, dismissal remedy |
| Part 5 disclosure / questioning | discovery-evidence pathway | source material, questioning type, undertakings, privilege |
| Part 6 applications | application-evidence pathway | evidence type, admissibility, transcript source, relief sought |
| Part 10 costs | costs-discretion pathway | success, conduct, offer, tariff, sanction |
| Applications Judge appeals | Rule 6.14 appeal-record pathway | record, additional evidence, standard of review, leave |
| Implied undertaking / cross-use | Rule 5.32/5.33/6.11 pathway | source material, use purpose, proceeding relationship, admissibility |

Load rule-specific references only after choosing the route.
